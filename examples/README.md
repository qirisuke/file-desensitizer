# 样例

`before/` 与 `after/` 是同一份文档脱敏前后的对照，**由工具自身生成**，保证文档与真实行为一致。

## 如何复现

```bash
# 1) 把 before/ 当作待处理目录
python app.py
#    目标目录填 examples/before

# 2) 配置
#    模式：组合（先屏蔽后替换）
#    关键词规则：示例能源  ->  示例集团
#    自定义敏感词表：示例能源
#    内置字段库：全选
#    内容掩码：***
#    文件名掩码：已脱敏

# 3) 扫描预览 -> 确认执行
```

结果与 `after/` 一致：`示例能源_经营情况.txt` → `已脱敏_经营情况.txt`，内容 38 处替换。

## 数据说明

文档中所有号码（身份证、银行卡、统一社会信用代码、手机号）均为**虚构值**：

- 长度、前缀、字符集合法，正则可正常命中
- **校验位被故意写错**（身份证 mod 11、银行卡 Luhn、统一社会信用代码 mod 31）

因此这些号码在任何权威系统中都判定为无效，不可能对应真实自然人或真实主体。
